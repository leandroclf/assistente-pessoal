# Dependências e Configuração

## Bibliotecas e Frameworks
- **Web Speech API** (navegador): Reconhecimento de voz na interface web.
- **n8n**: Plataforma de automação de fluxos.
- **OpenAI API**: Geração de texto e síntese de voz.

## Variáveis de Ambiente e Configuração
- Webhook de backend deve ser configurado na interface web (`COLOQUE AQUI SEU WEBHOOK`).
- Credenciais da OpenAI configuradas no n8n.

## Requisitos de Execução
- Navegador compatível com Web Speech API (Chrome recomendado).
- Instância do n8n configurada e ativa.
- Conta e chave de API da OpenAI.

## Instalação
1. Configurar o webhook do backend no HTML.
2. Subir o fluxo no n8n.
3. Configurar credenciais da OpenAI no n8n.

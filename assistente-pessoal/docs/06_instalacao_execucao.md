# Instalação e Execução

## Pré-requisitos
- Navegador Google Chrome (ou compatível com Web Speech API)
- Instância do n8n
- Conta e chave de API da OpenAI

## Passos de Instalação
1. Clone o repositório e acesse a pasta `assistente-pessoal`.
2. Configure o webhook do backend no arquivo `assistente_interface.html`.
3. Importe o fluxo `fluxo_n8n.json` no n8n.
4. Configure as credenciais da OpenAI no n8n.
5. Inicie o n8n e acesse a interface web pelo navegador.

## Execução
- Clique na "bola flutuante" para iniciar a interação por voz.
- Fale sua pergunta e aguarde a resposta em áudio.
